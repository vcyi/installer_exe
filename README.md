# 安装包制作工具（Installer Studio）

这是一个面向打包人员的 Windows 安装包制作工具。制作台与最终安装器均采用原生 Windows Forms 窗口，不启动浏览器、不监听本地 HTTP 端口。

## 安装模式

打包人员在制作台中决定最终安装器的可用模式，最终用户无法查看或修改构建配置。

- **基础安装**：仅复制内嵌的基础程序，不下载外部资源。开启 `allowInstallPathSelection` 后，基础/快速安装会先显示路径选择步骤；否则使用默认安装目录。
- **自定义安装**：仅在制作台开启“允许用户自定义安装”后显示。用户可选择安装目录，并勾选配置好的可选资源进行下载。
- **关闭自定义安装**：最终用户只会看到基础安装入口；仍可通过 `allowInstallPathSelection` 单独允许选择路径。

## 制作台功能

在 `installer_exe` 目录中双击 `启动原生制作台.cmd`，或运行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\installer-studio-native.ps1
```

首次启动会编译制作台源码，随后直接打开 Windows 桌面窗口。制作台启动时默认读取同目录的 `build-config.json`；控件修改后会自动防抖保存，关闭窗体前也会再次保存，因此下次打开会恢复上次配置。仍可导入、导出或手动保存配置。

| 配置分类 | 可设置内容 |
|---|---|
| 产品与目录 | 产品名称、版本、发布者、副标题、基础程序目录、主 EXE、默认安装目录、输出目录、图标、安装准备界面 Logo |
| 安装模式 | 是否允许最终用户选择自定义安装；是否允许基础/快速安装选择路径（`allowInstallPathSelection`） |
| 系统 Path | `addToSystemPath` 开关与 `systemPathValue`（制作台“Path 路径”，默认 `{app}`）。开启后仅将解析值写入 HKLM 的系统 `Path`，需要管理员权限；`{app}` 会替换为实际安装目录。 |
| 快捷方式 | 是否创建桌面快捷方式、开始菜单快捷方式 |
| 启动项 | 是否写入当前用户启动项、启动项名称、启动参数 |
| 外部资源 | 资源名称、下载 URL、是否必选、解压路径 |
| 卸载清理 | 是否删除桌面快捷方式、开始菜单、启动项和整个安装目录 |

“安装准备界面 Logo”对应配置字段 `prepLogoPath`，支持 PNG、JPG/JPEG、BMP；建议使用正方形透明 PNG。构建时该文件会复制到独立临时目录并作为 `preparation-logo` 嵌入最终启动器；未配置时会继续显示默认图形。

点击“扫描基础程序目录”可核对待打包文件数量和体积。确认配置后点击“开始构建”，制作台会显示构建进度、日志和最终安装包位置。

## 卸载行为

安装完成后，安装器会在当前用户的“应用和功能/控制面板”中写入卸载项，同时在安装目录保存卸载程序与卸载清单。

卸载时会按照制作台的配置执行以下操作：

- 删除对应的桌面快捷方式。
- 删除对应的开始菜单目录。
- 删除当前用户启动项。
- 仅删除本安装包实际写入并记录的那一项 HKLM 系统 `Path`；不会写入或删除任何用户环境变量，并保留其余 Path 内容后发送环境变量变更通知。
- 删除卸载注册表项。
- 可选删除整个安装目录，包括其中的用户生成文件。

默认不删除整个安装目录，避免意外清除用户数据。若启用该选项，应在制作台中明确确认该目录不含需要保留的数据。

## 外部资源说明

每项资源均可配置名称、下载 URL、是否必选和 `extractPath`。基础安装不下载资源；自定义安装时，必选资源会自动选中，可选资源由最终用户勾选。

`extractPath` 必须是相对安装目录的路径：安装器拒绝绝对/rooted 路径及包含 `..` 后逃逸安装目录的路径。下载后的 ZIP 会在目标目录中安全解压，并检查压缩包条目不能越界；非 ZIP 文件将原样保留在该目标目录。

## 构建架构

```text
原生制作台 → build-config.json → build-worker.ps1 → Setup.exe

最终 Setup.exe
  └─ C# 启动器：请求管理员权限、显示准备进度并提取内嵌负载
      └─ Inno Setup 负载：以可见模式解压基础程序和安装器到临时目录
          └─ C# WinForms 安装器：基础安装 / 自定义安装 / 卸载

启动器按实际写入的载荷字节以不超过 64 KB 的缓冲区提取，并节流刷新百分比。载荷完整提取到 100% 后以普通可见模式启动 Inno Setup；检测到由载荷启动的 `installer-app.exe` 后，准备窗口即关闭，不等待安装器完成。
```

`build-worker.ps1` 会把制作台配置嵌入最终安装器，随后复制基础程序、调用 Inno Setup 压缩负载，并输出 `<产品名称>-Setup-<版本号>.exe`。

## 环境要求

- Windows 10/11
- PowerShell 5.1+
- .NET Framework 4.0+
- Inno Setup 6.2+，默认安装位置为 `C:\Program Files (x86)\Inno Setup 6\`

## 常见问题

### 找不到 ISCC.exe

安装 Inno Setup 6 到默认目录，或设置环境变量 `INNO_SETUP_PATH` 指向包含 `ISCC.exe` 的目录。

### 原生制作台无法启动

使用 `启动原生制作台.cmd` 启动，或使用上面的 `-NoProfile -ExecutionPolicy Bypass` 命令。
